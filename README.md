# 苏轼的一生 · 人生如逆旅

一个交互式水墨长卷网站，以「七卷」结构呈现北宋文豪苏轼（1037—1101）的一生。

## 内容结构

| 卷次 | 主题 | 说明 |
|---|---|---|
| 卷一 | 数字东坡 | 以关键数字勾勒一生（19 岁娶妻、22 岁进士、130 日乌台诗狱、66 岁卒于常州…） |
| 卷二 | 一生年轮 | 按北宋六帝在位时期分卷的年表，可按「家事 / 仕途 / 文学 / 贬谪 / 民生」筛选 |
| 卷三 | 千里行迹 | 北宋疆域地图，十六城行迹连线，点击查看每地经历 |
| 卷四 | 词章千古 | 十三篇代表作，含创作背景、名家书法绘画 |
| 卷五 | 四海知交 | 十八位深交之人的关系网络，按亲密度分布 |
| 卷六 | 人间清欢 | 东坡所喜草木、四时、饮食 |
| 卷七 | 千古风流 | 身后回响与名句 |

## 技术特点

- **单文件主页面**：`index.html` / `苏轼的一生.html`，样式与交互全部内联，无构建步骤
- **完全离线可用**：所有图片、字体、配音、背景音乐、图表库（ECharts 内联）均为本地资源，无外部 CDN 依赖
- **双端适配**：桌面与移动端独立布局（移动端地图自动切换为城市卡片轮播）
- **专业配音**：25 段诗词朗读由 MOSS TTS「AI播音」音色预生成，本地播放，与背景音乐互斥
- **无障碍**：语义化标签、键盘可达、`prefers-reduced-motion` 适配

## 目录

```
index.html              部署入口（与主文件内容一致）
苏轼的一生.html           主文件
assets/
  art/                  水墨插画（城市 / 朝代 / 人物 / 词章 / 草木 / 四时 / 饮食 / 书画）
  audio/                25 段预生成诗词配音
  fonts/                本地字体（楷体、思源宋体）
  music/                背景音乐
```

## 本地运行

直接用浏览器打开 `index.html` 即可，无需服务器。

如需语音等部分功能的最佳体验，建议起一个本地服务：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000/
```
